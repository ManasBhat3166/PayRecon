# Screenshots

No screenshots are bundled: the project was built and verified in a headless Linux
environment with no browser, so none could be captured honestly.

To add your own after launching the app (`python -m streamlit run app.py`), save PNGs here:

| Suggested file | What to capture |
|---|---|
| `01_overview.png` | Overview tab: summary cards and charts |
| `02_discrepancies.png` | Discrepancies tab with the type filter |
| `03_transaction_detail.png` | Transaction details for the orphan refund |
| `04_download.png` | Download report tab |
